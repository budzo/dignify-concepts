# Dignify design concepts

Static HTML/CSS/JavaScript mockups: three homepage concepts, each with Meet the Team and About Dignify interior pages. Open `index.html` to compare. All fonts and imagery are bundled locally.

## GitHub Pages

Publish the repository root from the `main` branch under Settings → Pages → Deploy from a branch. No dependencies or build step are needed.

## Preview locally

Run `python3 -m http.server 8765` from this folder, then open http://localhost:8765.

## Scope

Design previews only. Newsletter forms do not submit or store email addresses. Snapshot and meeting links go to Dignify’s existing services.

Brand and team imagery: Dignify. Stock photography: Unsplash. Typeface: Work Sans.
